# 🎮 1 IN METHI

เว็บเกมตอบคำถามและมินิเกมสุดมันส์ในรั้วโรงเรียน สัมผัสบรรยากาศความสนุก พร้อมเก็บสะสมเหรียญเพื่อปลดล็อกแฟชั่นสุดเท่!

---

## ✨ ฟีเจอร์เด่นภายในเกม
* 🏫 **บรรยากาศโรงเรียนสุดเรียล:** ผจญภัยและพบปะกับเหล่า NPC ภายในโรงเรียน
* 🧮 **มินิเกมวัดสมอง:** ท้าทายความเร็วและความคิดด้วย **เกม 24** และ **เกม 180 IQ**
* 👗 **ระบบแฟชั่น & ร้านค้า:** นำเหรียญที่ได้จากการทำภารกิจมาซื้อชุดและเครื่องแต่งกายสุดชิค
* 📱 **รองรับการเล่นบนมือถือ:** ควบคุมง่ายผ่านปุ่ม D-Pad บนหน้าจอสัมผัส
